# ClipNode App 作品展示

[English](showcase.md)

这一页用于展示 ClipNode Android App 可以完成的作品能力。转场是第一组展示能力；后续可以继续增加 GIF 编辑、贴纸、图片合成、视频压缩、HLS 导出和模板等内容。

ClipNode 内置了大量 GL 视频转场动画，可用于回忆视频、图片轮播、产品短片、社媒短视频和混合素材剪辑。下面用视频展示不同转场类别的视觉能力。

点击任意 YouTube 链接即可观看演示。
