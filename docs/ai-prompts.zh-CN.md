## 分支

| 分支 | 说明 | 从这里开始 |
|---|---|---|
| 任务 prompts | headless 媒体任务的自然语言示例。 | [ai-prompts-task-workflows.md](ai-prompts-task-workflows.zh-CN.md) |

## 阅读顺序

1. 先选和任务目标一致的分支。
2. 把示例当模板，不要当死板脚本。
3. 如果 prompt 里需要 patch 或 source，先读对应能力分支。
4. 如果用户已经在编辑页，优先看会话 patch 分支。

## 规则

- prompt 要短、目标明确。
- 要说明输出、风格和保存位置。
- 具体工具形状交给能力层决定。
- 不要把不相关的任务家族混在一个 prompt 里，除非任务本身确实跨域。
