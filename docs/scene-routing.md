# Scene Routing

[中文版本](scene-routing.zh-CN.md)

This is the shortest first step when you are trying to choose a path.

## Pick One

| Situation | First move | Then read |
|---|---|---|
| New output | Start the export-task tree | [capabilities-task-workflows.md](capabilities-task-workflows.md) |
| Current session edit | Read current state first | [capabilities-live-session-patching-core.md](capabilities-live-session-patching-core.md) |
| Need source media | Open the media-sources branch | [capabilities-media-sources.md](capabilities-media-sources.md) |

## Rule

- If you are making a new finished result, go to export tasks.
- If you are modifying the open draft, go to live session patching.
- If you only need files or paths, go to media sources.
