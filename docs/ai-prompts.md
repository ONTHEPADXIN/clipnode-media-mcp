## Reading Order

1. Choose the branch that matches the task.
2. Use the prompt as a template, not as a rigid script.
3. If the prompt needs patches or sources, read the matching capability branch first.
4. If the user is already on the edit page, prefer the live-edit branch.

## Rule Of Thumb

- Keep prompts short and goal-focused.
- Mention the desired output, style, and destination.
- Let capabilities decide the exact tool shape.
- Do not mix unrelated task families in one prompt unless the task truly spans them.
