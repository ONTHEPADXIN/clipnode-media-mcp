# ClipNode App Showcase

[中文说明](showcase.zh-CN.md)

This page introduces what the ClipNode Android app can create. Transitions are the first showcased capability; more sections can be added later for GIF editing, stickers, image composition, video compression, HLS export, and templates.

ClipNode includes a large GL transition library for video composition. These examples show the visual range available for memory videos, slideshow edits, product clips, short-form social videos, and mixed media compositions.

Click any YouTube link to watch the demo.
